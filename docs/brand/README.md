# Leadlens brand

The Leadlens mark is a lens dot between token braces, `{ ● }`. It comes from Marketo's personalisation tokens, such as `{{lead.FirstName}}`, which are where the name comes from. The wordmark is written `lead.lens`, with the dot in the lens colour.

## Files

| File | Use |
|---|---|
| `leadlens-icon.svg`, `leadlens-icon-1024.png` | The app icon: mark on its ink tile. Use from 48 px up. |
| `leadlens-icon-small.svg`, `leadlens-favicon-32.png`, `leadlens-favicon-16.png` | Heavier braces and a larger dot for 32 px and below, such as favicons and tab icons. |
| `leadlens-lockup-light.svg` / `.png` | Icon and wordmark for light backgrounds. |
| `leadlens-lockup-dark.svg` / `.png` | Icon and wordmark for dark backgrounds. |
| `leadlens-social.png` | GitHub's social preview card (1280 × 640). |
| `leadlens-product.png` | The README's header image: the website's product illustration, rendered at 2× (2400 × 1188) with transparent corners. Re-render it if the illustration in `site/src/components/ProductShot.astro` changes. |
| `leadlens-demo.gif` | The README's demonstration (1280 px wide, about 18 seconds), recorded from the packaged extension in VS Code. It uses `samples/marketo-newsletter.html` without the button's VML fallback: `padding` is typed into the call-to-action button, its warning is hovered, the preview switches from Gmail to Outlook Classic, and the Quick Fix menu opens. Record it again if the preview's layout changes noticeably. |
| `../icon.png`, `../icon.svg` | The extension icon VS Code shows (256 px PNG). |
| `../../media/preview-light.svg`, `../../media/preview-dark.svg` | The preview tab icon: the glyph without its tile, for light and dark themes. |

The wordmark is converted to outlines, so the files don't depend on any font being installed. All files except `leadlens-product.png` and `leadlens-demo.gif` are generated by `source/generate.mjs` (its header explains how to run it); change the source and regenerate rather than editing the outputs by hand.

## Colour

| Name | Hex | Use |
|---|---|---|
| Ink | `#121A2B` | Icon tile, dark backgrounds, text on light. |
| Lens | `#3FD6C1` | The dot and accents on dark backgrounds. Too light for text or small marks on white. |
| Deep lens | `#0E8F80` | The wordmark dot, links and accents on light backgrounds (4:1 on white). |
| Mist | `#E9EEF5` | Light surfaces and panels. |
| Slate | `#5B6B82` | Secondary text on light backgrounds (5.4:1 on white). |
| Paper | `#F4F7FB` | The braces, and text on Ink. |

On dark backgrounds that aren't Ink, the dark lockup uses a slightly lighter tile (`#1B2640`) so the icon's edge stays visible.

## Type

- **IBM Plex Mono SemiBold:** the wordmark and headings.
- **IBM Plex Sans:** body text.

Both are free under the SIL Open Font License 1.1 and available from Google Fonts.

## Usage

- Leave clear space around the icon of at least a quarter of its width.
- Don't recolour the braces, change the tile shape, or set the wordmark in another font.
- Don't use Adobe or Marketo logos alongside it, or Marketo's purple or Adobe's red as brand colours. Leadlens is compatible with Adobe Marketo Engage, not part of it.
- Refer to Marketo only in referential phrases such as "for Adobe Marketo Engage", together with the trademark notice in the main README.
