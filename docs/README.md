# Leadlens documentation

Leadlens is a VS Code extension for previewing and linting HTML email, with first-class support for Adobe Marketo Engage Email Editor 2.0.

## Using Leadlens

- [Getting started](getting-started.md): install Leadlens, open your first preview and read your first findings.
- [Previews](previews.md): the 21 client simulations, comparisons, light and dark mode, viewports, client sets and local images.
- [Marketo Email Editor 2.0](marketo.md): templates, variables, tokens, preview values, components in templates, prepared HTML and editor navigation.
- [Linting](linting.md): what's checked, how findings appear, scores, quick fixes and silencing findings.
- [Configuration](configuration.md): every setting, team configuration files and how they combine.
- [Privacy and security](privacy-and-security.md): what Leadlens does and doesn't access.
- [Troubleshooting](troubleshooting.md): answers to common problems.
